# Welcome to RedTide ppc (RTP)

Welcome! RTP is our school prototype for coastal community records in Puerto Princesa, Palawan. This space is for questions, ideas and project news.

Start with the [community guide](https://github.com/franshessss2/red-tide-ppc/blob/main/docs/community/wiki/Home.md), [website](https://red-tide-ppc.vercel.app/) or [public map](https://red-tide-ppc.vercel.app/map).

## Where to post

- **Q&A:** how to use the app, build it or troubleshoot a setup.
- **Ideas:** a proposed feature or visual improvement and the problem it would solve.
- **Show and tell:** your school demonstration or contribution. Remove private/personal details from screenshots.
- **Issues:** reproducible software bugs belong in the [issue tracker](https://github.com/franshessss2/red-tide-ppc/issues).

Describe your device, version, route and what happened. Never post env files, private credentials or device tokens. Coastal observations belong in the app's report form rather than GitHub.

## What is available

The website runs on Vercel. The Android debug alpha is available through the [shared download folder](https://drive.google.com/drive/folders/1mpUalyCgYrDXoN8L1KP7WVv11_p-VFSJ?usp=sharing). Windows packaging is merged in PR #102 under **RedTide ppc**, short name **RTP**; the unsigned installer was tested locally but a Windows release asset is not published yet. Native Wiki publication is also pending; the repository guide above is readable now.

Check **Sample data** and the source details. Local sample reports do not sync between website, Android and Windows. Community warnings are not official BFAR advisories, and no recorded warning is not seafood clearance. Use [BFAR bulletins](https://www.bfar-frmdhabmonitoring.com.ph/shellfishBulletinFile) for official advice.

Please keep conversations respectful and specific. Thanks for helping improve the prototype.
